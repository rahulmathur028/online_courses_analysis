# 🎓 Online Course Analysis Dashboard

## 📌 Project Overview
This project features an interactive **Power BI Dashboard** built to analyze student enrollment, revenue generation, and engagement patterns across various online courses. The goal of this analysis is to provide e-learning platforms or educators with actionable insights into course performance, student demographics, and financial metrics to help optimize marketing strategies and course content.

## 📊 Key Features & Dashboard Breakdown
The dashboard delivers data-driven insights through key business metrics and specialized visuals:

* **Executive KPI Summary:** Quick view of high-level performance indicators such as **Total Revenue**, **Total Enrollments**, **Average Course Ratings**, and **Active Students**.
* **Financial & Revenue Insights:** Breakdown of revenue across different course categories, subscription levels, and pricing tiers to understand profitability drivers.
* **Course Performance Analysis:** Comparison of various courses based on their completion rates, student reviews, and total sign-ups to identify "Bestsellers" and underperforming topics.
* **Student Demographics & Engagement:** Geographical and professional segmentation of learners to understand target audience behavior and peak learning times.
* **Interactive Filtering:** Built-in slicers for time periods (Months/Quarters), course levels (Beginner, Intermediate, Advanced), and categories for granular data exploration.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For advanced data modeling, metric creation, and canvas design.
* **Power Query:** Utilized for data cleaning, text formatting, and transforming raw platform logs into structured tables.
* **DAX (Data Analysis Expressions):** Used to build dynamic measures like *Cumulative Revenue, Year-over-Year (YoY) Enrollment Growth, and Retention Rates*.

## 📂 Project Repository Structure
* `powerbi_project_OnlineCourseAnalysis.pbix`: The core Power BI project file containing the data model and visualizations.
* `online_course_analysis.jpg`: A high-resolution preview screenshot of the dashboard interface.

## 🚀 How to Explore the Dashboard
1. **Prerequisite:** Make sure you have [Microsoft Power BI Desktop](https://powerbi.microsoft.com/) installed on your machine.
2. Clone or download this repository to your local system.
3. Open the `powerbi_project_OnlineCourseAnalysis.pbix` file.
4. Interact with the dynamic charts, drop-downs, and cross-filtering elements to see the data update in real-time.
